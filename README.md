# AI Summit Barcelona 2026: build your agenda

The official programme lists 140 sessions across six stages over two days, with filters but no way to pick sessions or see what overlaps. This page adds that.

Live: https://fernandocucci.github.io/aisummit-agenda/

- Tick sessions. Sessions in the same row start at the same time, so a pick greys out the alternatives.
- Overlapping picks are flagged on the card.
- Export your picks as an `.ics` file for any calendar.
- Copy the link: your picks travel in the URL, so you can share an agenda with a colleague.

Unofficial tool, not affiliated with the organisers. Programme data comes from the public schedule at [aisummitbarcelona.com](https://aisummitbarcelona.com/schedule) and can be refreshed with `python3 scrape.py`.

Single HTML file, no build step, no backend.
